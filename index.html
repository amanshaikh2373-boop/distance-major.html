How it works
The AI detects common objects automatically. Distance is estimated from the object's bounding-box width and an approximate real-world object width. It does not require you to type the object size.

Accuracy: approximate. Different object sizes, camera lenses and viewing angles affect the result. A phone with depth/AR hardware can provide better measurements.
